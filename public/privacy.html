Personuppgiftsansvarig

ScentPlugSweden ansvarar för behandlingen av personuppgifter i samband med webbplatsen och våra kunders köp.

Vilka uppgifter vi behandlar

  • Namn och kontaktuppgifter, exempelvis e-postadress.
  • Leverans- och faktureringsuppgifter som behövs för att genomföra ett köp.
  • Orderuppgifter, exempelvis ordernummer, produkter, belopp och orderstatus.
  • Information som du lämnar till oss vid kontakt med kundservice.
  • Tekniska uppgifter som behövs för drift, säkerhet och felsökning.

Varför vi behandlar personuppgifter

  • För att hantera och leverera beställningar.
  • För att behandla betalningar och återbetalningar.
  • För att hantera kundservice, returer och reklamationer.
  • För att uppfylla rättsliga skyldigheter, exempelvis bokföringskrav.
  • För att skydda webbplatsen och förebygga missbruk.

Rättslig grund

Personuppgifter behandlas när det behövs för att fullgöra ett avtal med dig, uppfylla rättsliga skyldigheter eller för våra berättigade intressen, exempelvis säkerhet och kundservice. När samtycke krävs behandlar vi uppgifterna på grundval av ditt samtycke.

Betalning

Betalningar kan behandlas av Stripe. Vi hanterar inte fullständiga kortuppgifter själva när betalningen sker via Stripe. Stripe behandlar personuppgifter enligt sina egna villkor och sin integritetspolicy.

Leverans

För att kunna leverera beställningar kan nödvändiga leveransuppgifter delas med transportörer, exempelvis PostNord.

Tekniska leverantörer

Webbplatsen kan använda tekniska tjänster för hosting, drift och säkerhet, exempelvis Railway. Sådana leverantörer kan behandla tekniska uppgifter som behövs för att tillhandahålla tjänsten.

Lagringstid

Vi sparar personuppgifter endast så länge de behövs för det ändamål de samlades in för eller så länge lagen kräver det. Order- och bokföringsuppgifter kan behöva sparas under den tid som krävs enligt bokföringsregler.

Dina rättigheter

Du kan, beroende på omständigheterna, ha rätt att begära tillgång till dina personuppgifter, rättelse, radering, begränsning av behandling, dataportabilitet och att invända mot viss behandling. Om behandlingen grundar sig på samtycke kan du återkalla ditt samtycke.

Kontakta oss på Scentplugsweden@gmail.com om du vill utöva dina rättigheter.

Klagomål

Du har rätt att lämna klagomål till Integritetsskyddsmyndigheten (IMY) om du anser att dina personuppgifter behandlas felaktigt.

Ändringar

Vi kan uppdatera denna integritetspolicy när våra tjänster eller rättsliga krav förändras. Den aktuella versionen publiceras på webbplatsen.

Kontakt: Scentplugsweden@gmail.com
